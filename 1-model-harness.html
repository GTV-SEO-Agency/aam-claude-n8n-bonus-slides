Bắt đầu bằng một câu hỏi

      
Cùng là Claude Opus 5.5, vì sao chỉ một chỗ cài được n8n lên máy bạn?

      

        

          
Chat
Trả lời, viết, phân tích file bạn gửi. Không chạy lệnh trên máy bạn.

          
Cowork
Làm việc nhiều bước với folder bạn cho phép. Lệnh chạy trên máy chủ của Anthropic.

          
Code
Chạy lệnh thẳng trên máy bạn, nên cài được Docker và n8n.

        

        
Câu trả lời nằm ở hai chữ: model và harness. Ba slide sau giải thích từng chữ.

      

    

  


  
  

    

      
Phần 1 · Model là gì

      
Model là bộ não: nhận chữ, nghĩ, rồi trả lời bằng chữ

      

        

          
Bạn gửi
câu hỏi, đề bài,
file đính kèm

          
→

          
Model
Opus · Sonnet · Haiku
(Claude 5.5)

          
→

          
Model trả về
câu trả lời, bản nháp,
câu lệnh nên chạy

        

        

          
Model quyết định: hiểu đề có đúng không, nghĩ có sâu không, viết có rõ không.

          
Dễ hiểu nhầm: model không tự mở file hay tự chạy lệnh. Nó chỉ viết ra lệnh nên chạy. Phải có thêm một lớp nữa mới chạy được.

        

      

    

  


  
  

    

      
Phần 1 · Harness là gì

      
Harness là lớp bọc quanh model, giúp model làm việc thật

      

        

        

          
Công cụ
Chạy lệnh, đọc và sửa file, gọi MCP, mở trình duyệt.

          
Quyền
Việc nào tự làm, việc nào phải hỏi bạn. Ví dụ: được soạn nháp email, không được bấm gửi.

          
Luật
File hướng dẫn trong folder, ví dụ AGENTS.md.

          
Nơi chạy
Trên máy bạn, hay trên máy chủ của hãng.

        

      

    

  


  
  

    

      
Phần 1 · Hình dung cho dễ

      
Model là bộ não, harness là tay chân

      

      
Rút ra: bộ não giỏi nhất mà không có tay chân thì chỉ nói được "bạn nên chạy lệnh này". Muốn Claude tự cài n8n trên máy bạn, Claude cần harness có tay chạy lệnh và chân đứng trên máy bạn.

Phần 2 · Hạn mức của gói

      
Gói Claude có hai mức trần: theo 5 giờ và theo tuần

      

        

          
Trần theo 5 giờ
Dùng hết thì chờ tới khung 5 giờ tiếp theo, hạn mức tự hồi lại.

          
Trần theo tuần
Tính cộng dồn cả tuần, kể cả khi mỗi khung 5 giờ bạn chưa dùng hết.

          
Gói Pro 20 USD
Gói Max 100 USD dùng được gấp 5 lần Pro. Pro đủ để học và làm bài trong khoá.

        

        
Lời khuyên cho người mới: dùng Chat để hỏi và lên ý tưởng, dùng Code để làm việc thật trên máy. Tạm bỏ qua Cowork, vì Cowork tốn lượt và không cài được phần mềm lên máy bạn.

      

      
Nguồn: Claude Help Center, bài "How do usage and length limits work?" và "What is the Max plan?" (Max bản 100 USD = 5 lần Pro mỗi 5 giờ và mỗi tuần), xem ngày 08/11/2026.

    

  


  
  

    

      
Phần 3 · n8n + Claude Code

      
Claude làm phần kỹ thuật, bạn chỉ làm 5 việc máy bắt buộc người làm

      

        

          
Claude

            
Khám máy
Chạy Docker
Dựng n8n

Dựng, sửa workflow
Đọc lỗi, sửa lỗi

          
Bạn

            
·

n8n chạy việc tự động trên máy bạn, miễn là máy đang bật. Claude Code là người dựng và sửa workflow cho n8n. Bạn không cần mở Terminal.

      

    

  


  
  

    

      
Phần 3 · Ai duyệt lệnh

      
Chọn Auto để Claude tự chạy lệnh thường ngày

      

        

        
    
          
  1. Auto: Claude tự chạy lệnh. Một bộ lọc an toàn chặn lệnh nguy hiểm trước khi chạy.
    2. 
          
  2. Manual: hỏi bạn trước mọi thay đổi. Chậm, hợp khi mới làm quen.
    3. 
          
  3. Accept edits: tự sửa file, hỏi trước khi chạy lệnh. Kit chọn sẵn chế độ này.
    4. 
          
  4. Plan: chỉ đọc và lập kế hoạch, chưa sửa gì.
    5. 
        
Dễ hiểu nhầm: Auto vẫn hỏi bạn ở vài lệnh, ví dụ tải phần mềm từ internet hay mở n8n ra internet. Đọc câu Claude giải thích rồi bấm cho phép.

      

      
Ảnh chụp app Claude Desktop, tab Code, ngày 08/11/2026. Chế độ chọn ở đây được nhớ theo folder.

    

  


  
  

    

      
Phần 3 · Harness dựng sẵn cho bạn

      
Mở folder kit, bấm Trust: luật và quyền đã có sẵn

      

        

        
    
          
  1. Folder bạn chọn: Claude chỉ làm việc trong folder này.
    2. 
          
  2. Execution allowed by: file .claude/settings.json của kit ghi sẵn lệnh nào được tự chạy, lệnh nào phải hỏi.
    3. 
          
  3. Trust workspace: bấm để Claude đọc luật trong AGENTS.md, skill cài n8n và plugin n8n-skills.
    4. 
        
Dùng app Claude Desktop, không dùng bản trên trình duyệt: bản trình duyệt không chạy lệnh trên máy bạn. Mỗi mảng việc một folder riêng, ví dụ folder n8n, folder content.

      

      
Ảnh chụp app Claude Desktop, tab Code, ngày 08/11/2026. Tên tài khoản máy đã che.
